## Architecture principles
FOSIS is an AI-first, multi-tenant Student Information System covering nursery through Year 13. The architecture is API-first, standards-aligned (including OneRoster 1.2 where applicable), auditable, configurable by school, and designed to minimise unnecessary personal data exposure. Human approval remains authoritative for high-impact decisions.
